MemoryDeck — 快速上手
================================================================

  一个本地记忆卡片管理器。以 Markdown 为唯一数据源，
  把长期记忆变成 AI 每一轮都能读到的上下文。


一、跑起来
----------------------------------------------------------------

  1. 双击 MemoryDeck.exe

  2. 第一次打开时，程序会问你数据目录在哪。
     如果没有 MEMORY.md，它会自动建一份干净的。

     想换目录：菜单 数据(D) → 数据目录…


二、最少需要记住的三个快捷键
----------------------------------------------------------------

  Ctrl+N        新增一条记忆
  Ctrl+S        保存
  Ctrl+D        收起 / 展开下方详情区

  其他：
  Ctrl+E        编辑选中条目（也可以直接双击表格行）
  Ctrl+F        跳到搜索框
  Delete        删除选中条目（会先自动备份）
  F5            重新加载文件
  右键表格行      查看完整信息 / 复制 / 编辑 / 删除


三、把记忆喂给网页版 AI
----------------------------------------------------------------

  这是它最有用的一步。

  1. 菜单 数据(D) → 导出给网页版 AI…   （或按 Ctrl+Shift+E）

  2. 弹出的窗口里就是可以直接复制的一段纯文本。
     右下角会显示体量，例如「263 字符 / 约 202 tokens」。

  3. 点「复制到剪贴板」

  4. 打开 ChatGPT / Claude / DeepSeek 等网页版，
     新建对话，Ctrl+V 粘贴，发出去。

  它生成的不是 Markdown 表格——那种格式粘进聊天框会变成
  一堆竖线，难读也不像人话。这里生成的是按类别分组的纯文本。


四、它和 AI 是怎么同步的
----------------------------------------------------------------

  数据目录里有两个文件：

    MEMORY.md    全部记忆条目（你手改也行）
    AGENTS.md    AI 每轮自动加载的摘要

  程序只重写 MEMORY.md 里那张表格。表格之前和之后的文字
  （你写的说明、约定）都会原样保留。

  每次写入后会重建 AGENTS.md 的摘要标记区，
  这样 AI 在新会话里加载到的记忆永远是最新的。

  程序每 1.5 秒检查一次文件指纹：
  你在记事本里改完保存，界面 2 秒内会自动刷新。


五、安全网
----------------------------------------------------------------

  · 每次写入前自动备份到  <数据目录>\.memory-deck\backups\
    最多保留 30 份，超出自动清理。

  · 原子写入：先写临时文件再替换，断电不会留下半截文件。

  · 想手动整理格式：命令行跑  MemoryDeck.exe --repair
    它会规范化重写并校验条目数无损。


六、命令行
----------------------------------------------------------------

  MemoryDeck.exe --selftest              跑 140 项自检
  MemoryDeck.exe --repair                规范化重写 + 校验数据无损
  MemoryDeck.exe --export -o 记忆.txt     导出到文件
  MemoryDeck.exe --env                   打印屏幕 / DPI / 窗口尺寸诊断
  MemoryDeck.exe --help                  全部选项


七、环境要求
----------------------------------------------------------------

  Windows 10 / 11（x64）
  .NET 10 桌面运行时

  如果提示缺运行时，去 https://dotnet.microsoft.com/download/dotnet/10.0
  下载「Desktop Runtime」装上即可。
