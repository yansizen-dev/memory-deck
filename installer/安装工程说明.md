# MemoryDeck 1.2.2 Windows 安装工程

本工程基于用户提供的 MemoryDeck 1.2.2 发布程序制作安装包装，没有修改原版 MemoryDeck.exe。
本工程包含安装器和启动器源码，不包含原应用 C# 源码；继续修改应用功能仍需要原应用工程。

## 已提供的安装行为

- 适用于 Windows 10 / 11 x64，当前用户安装，无需管理员权限。
- 安装路径：`%LOCALAPPDATA%\Programs\MemoryDeck`。
- 默认数据路径：`%LOCALAPPDATA%\MemoryDeck\Data`。
- 在默认数据目录缺少记忆文件时才复制空白模板，不覆盖已有数据。
- 安装目录缺少配置时才创建配置；使用已有配置时不重置数据目录。
- 桌面及开始菜单入口通过启动器使用私有 .NET 10.0.13 x64 运行时。
- 启动器只为子进程设置 DOTNET_ROOT / DOTNET_ROOT_X64，不修改系统环境变量。
- 运行时离线随附，不向系统全局安装 .NET。
- 卸载仅移除程序、随附运行时、快捷方式和卸载注册项；保留配置与数据。
- 软件内“数据目录”操作仍可写回配置。原程序已有的 `MEMORYDECK_DATA` 环境变量优先规则保留。

## 重建

安装 Python 3 和 NSIS 3。运行 `python build.py`。
若找不到编译器，设置 `MAKENSIS` 为 makensis.exe 的完整路径。
重建脚本从微软官方地址下载固定版本的运行时，校验发布元数据中的 SHA-512，再解压与编译。
首次重建需要联网；已有下载缓存且校验通过时可以离线重建。
Linux 编译可按本机 NSIS 布局设置 `NSISDIR`。

文件说明：

- `setup.nsi`：Windows 安装及卸载逻辑。
- `launcher.nsi`：原生 Windows 启动器，选择随附运行时后启动原程序。
- `payload/MemoryDeck.exe`：用户提供的原版应用。
- `payload/templates`：空白记忆模板；修正了自动加载能力的过度概括说明。
- `payload/使用指南.html`：离线使用说明。
- `runtime-provenance.json`：官方运行时下载地址及 SHA-512。
- `app.ico`：从用户提供的原程序提取，保留原有图标。
